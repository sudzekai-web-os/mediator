# mediator

Типизированный mediator для разделения команд и запросов от их обработчиков.

Пакет предоставляет:

- контракты команд, запросов и обработчиков;
- регистрацию обработчиков команд;
- выполнение команд;
- регистрацию обработчиков запросов;
- выполнение запросов с типизированным результатом.

## Установка

```bash
go get github.com/sudzekai-web-os/mediator
```

## Структура

* abstractions — интерфейсы команд, запросов и обработчиков.
* commanddispatcher — регистрация и выполнение команд.
* querydispatcher — регистрация и выполнение запросов.

## Обработчики команд

Обработчик команды реализует интерфейс:

```go
type ICommandHandler[TCommand ICommand] interface {
    Handle(TCommand) error
}
```

Регистрация и выполнение команды:

```go
commanddispatcher.RegisterHandler(createUserHandler)

err := commanddispatcher.Execute(createUserCommand)
if err != nil {
    // обработка ошибки
}
```

Команда не возвращает значение. Результатом выполнения является только error.

## Обработчики запросов

Обработчик запроса реализует интерфейс:

```go
type IQueryHandler[TQuery IQuery[TResult], TResult any] interface {
    Handle(TQuery) (TResult, error)
}
```

Регистрация и выполнение запроса:

```go
querydispatcher.RegisterHandler(getUserHandler)

user, err := querydispatcher.Query(getUserQuery)
if err != nil {
    // обработка ошибки
}
```

Результат запроса типизирован с помощью обобщений Go.

Важные особенности
Обработчики хранятся в глобальных реестрах и определяются по типу команды или запроса. Повторная регистрация обработчика для одного типа заменяет предыдущий обработчик.

Если обработчик не зарегистрирован, Execute или Query вызывает panic. Поэтому все обработчики должны быть зарегистрированы до выполнения соответствующих команд и запросов.

Регистрация обработчиков не защищена от конкурентного доступа. Выполняйте регистрацию до запуска параллельной обработки запросов.
